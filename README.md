# 鼠鼠桌宠

> 通用桌宠引擎 for SillyTavern。**扩展负责全部代码，作者只提供数据。**

---

## 它解决什么问题

把桌宠做进角色卡的话，整套代码会跟着卡走，于是：

- 每换一只桌宠都要重写一遍解析、渲染、拖拽、存档
- 代码跟着卡走，卡一改就丢，改一处要重导卡
- 位置、缩放、保活这些坑，每只桌宠都要重踩一遍

**鼠鼠桌宠把这两件事拆开了**：

| 谁 | 负责什么 |
|---|---|
| **扩展（这个项目）** | 标签解析、契约校验、立绘图层合成、动作播放、拖拽、点击气泡、位置存档、自动夹回、窄屏缩放、看门狗保活、根元素包含块修复 |
| **作者** | ① 一个标签名 ② 一份字段契约 ③ 一套立绘素材 |

作者**一行代码都不用写**，只需要在可视化编辑器里填表 + 贴图片 URL。

---

## 安装

把整个 `shushu-pet` 文件夹放进：

```
<SillyTavern>/data/default-user/extensions/shushu-pet/
```

然后**刷新酒馆页面**。左侧会出现一个「**鼠鼠桌宠**」按钮。

> 目录名必须是 `shushu-pet`（`manifest.json` 和入口脚本按它定位自己）。

## 三步用起来

### 1. 做一个桌宠包（可视化，不用写代码）

点左侧「**鼠鼠桌宠**」按钮 → 点 **「+ 新建桌宠包」**，然后填表：

| 步骤 | 你做什么 |
|---|---|
| ① 基本信息 | 桌宠名字、唯一 ID、**标签名**（默认 `PetState`） |
| ② 底图 | 贴一张底图 URL（必填） |
| ③ 表情/状态字段 | 加字段（如「眼睛」），每个取值贴一张 URL，并填**中文说明** |
| ④ 配饰 | 可选，**数量不限**，每张都能单独微调位置/大小 |
| ⑤ 台词 | 可选，气泡里说的话 |
| ⑥ 动作 | 勾选可用动作（呼吸/跳跃/转圈…共 12 种预设） |
| ⑦ 外观 | 尺寸 + **单个部位的位置/缩放/旋转微调** |
| ⑧ 消息框美化 | 气泡的全部样式参数 |

> **单个部位的微调**：每个取值旁边有个「微调」按钮，展开后能调
> **左右 / 上下 / 缩放 / 旋转 / 不透明度**。这是给"配件图没对齐"用的——
> 配件的图往往是随手画的，直接叠到底图上位置会很怪，调一下就好。
> 调过的按钮会变绿，一眼能看出哪些部位被改过；点「重置」还原。

> **消息框美化**：桌宠说话那个气泡可以全参数可视化调——
> 底色/渐变、字色、圆角、内边距、最大宽度、字号、行高、字距、字重、
> 边框、阴影、不透明度、位置偏移。
>
> **材质**：7 种一键预设（默认深色 / 毛玻璃 / 和纸 / 描边透明 / 霓虹发光 / 金属 / 淡色纸卡），
> 另有「毛玻璃模糊」「饱和度+」「内发光」「发光色」单独可调。
> 毛玻璃用 `backdrop-filter`，要配合半透明底色才看得出效果。
>
> **小尾巴**：**可以加任意多条**，每条独立选「贴图 / 纯色小三角 / 不用」，
> 并各自调宽高、右移下移、旋转、左右上下微调、不透明度。

**右侧有实时预览**——贴一张图就多一层，而且**预览会动**：

- 预览用的是和正式渲染**完全相同的尺寸、类名和 CSS**（所以预览里能动，挂上去就能动）
- 预览下方有 **「试动作」** 一排按钮，点哪个就播哪个（默认自动挑第一个有动画的）
- 尺寸按包里设置的来（如 `25.5vh`），不是写死的缩略图
- 下面那行绿字会写明**当前预览的是哪些取值**（如 `当前：眼睛=smile，配饰=tears`）

**预览和演示是同一份状态**——在演示控制条上点「smile」，预览立刻跟着变；在预览里点「转圈」，页面上的演示也跟着转。

### 导出的是什么？放哪？

编辑器有**两个导出按钮**：

| 按钮 | 产物 | 放哪 |
|---|---|---|
| **导出 JSON** | 桌宠**数据包**（标签名+字段契约+素材 URL） | 本扩展的「导入 JSON」按钮 |
| **导出独立脚本** | 一个自包含的 `.js`，**不依赖本扩展** | 酒馆助手 → 脚本库 → 新建 → 粘贴 |

**「导出独立脚本」是给别人用的**——对方不用装鼠鼠桌宠，只要装了酒馆助手，
把那个 `.js` 粘进脚本库就能跑。文件开头附带了要贴进角色卡的提示词，直接复制。

> 导出时会 `fetch` 扩展目录下的 `core/standalone-runtime.js`。
> 所以**导出必须在酒馆页面里操作**（不能拿这个文件夹去离线跑导出）。

### 为什么不能导出成「酒馆正则」

**技术上做不到。** 酒馆渲染消息前会过 DOMPurify + `MESSAGE_SANITIZE`
（`public/scripts/chats.js` 的 `addDOMPurifyHooks`），三条路都被堵死：

1. `<script>` 会被直接删掉
2. `onerror` / `onclick` 这类内联事件属性会被剥掉
3. 所有 class 会被加上 `custom-` 前缀，连"用 CSS 选择器触发布局"都做不到

正则只能做**文本替换**，没法执行代码、也没法跨消息保存状态。
所以能脱离扩展独立运行的只有「酒馆助手脚本」这一条路。

### 2. 绑定角色

面板里每张包上都有「**绑定当前角色**」和「**设为默认**」。
绑定后只有这张卡用；设为默认则所有卡都用它。

> **包存在哪？** 你导入/编辑过的包存在**浏览器的 localStorage** 里
> （键名 `shushu-pet:packages`），**不在服务端**。所以换电脑、换浏览器、
> 或清浏览器数据都会丢——重要的包记得点「导出 JSON」备份一份。
>
> 面板底部有 **「清空本机桌宠包」**（只清你导入的，内置模板保留）
> 和 **「清空全部本地数据」**（连绑定、默认包、桌宠位置一起清）。

### 3. 完事

模型输出标签，桌宠立刻变脸、做动作、说话。

生成的提示词是**世界书条目那种格式**：

```
【示例桌宠状态输出规则】
AI生成的所有内容最后都必须附带以下格式, 严禁照搬照抄, 根据剧情发展实时变更,
表情/动作要贴合当前剧情情绪, 实际生成时严禁输出任何注释和换行,
只输出单行紧凑 JSON, 标签名不可改, JSON 内出现双引号一律转义为 \"：
<PetState>{"eyes":"normal","motion":"still","speech":"在的。"}</PetState>

各字段说明：
  "eyes": 取一个: normal(平静)/happy(开心)/sad(难过)
  ...
```

其中 **`happy(开心)` 这种中文说明由你自己填**——
每个取值旁边有个 **「说明(给AI看)」** 输入框，每个字段还能填 **「字段补充说明」**
（比如"情绪大多数时候保持 still，禁止一惊一乍"）。
**填了才会出现在提示词里**，不填就只列取值名。

标题**跟着包的名字走**（`【<包名>状态输出规则】`），改名后重新保存即可生效。

```
shushu-pet/
├── manifest.json          扩展声明
├── index.js               入口：按顺序加载 core/ 并启动
├── style.css              面板兜底样式（桌宠本体样式由引擎动态生成）
├── core/
│   ├── util.js            日志、事件总线、安全存储、深合并
│   ├── dom.js             图层合成 + 动作 CSS + 气泡样式 + Shadow DOM 组装
│   ├── position.js        位置管理（整只可见 / 自动夹回 / 窄屏缩放）
│   ├── engine.js          渲染实例：挂载、更新、拖动、气泡
│   ├── adapter.js         酒馆接线：读消息、事件、根元素修复、看门狗
│   ├── registry.js        包注册表：按角色匹配包 + 包格式校验
│   ├── settings.js        设置面板 UI
│   ├── editor.js          可视化编辑器：填表 + 贴 URL → 生成规范包
│   ├── demo.js            演示/试跑：把正在做的桌宠放到页面上切取值试
│   ├── standalone-runtime.js  独立运行时：导出时拼进生成文件，脱离扩展也能跑
│   └── boot.js            总装
├── builtin/
│   └── example.json       内置空白模板（素材留空，填自己的 URL 即可）
└── docs/
    └── 包格式.md           手工写包的完整规范（用编辑器就不必看）
```

## 核心设计

### 数据来源：模型输出文本里的标签

**不调用任何 AI API**。引擎只从聊天记录里读最近的 AI 消息，用正则抠出标签内容。
好处：零成本、不占对话轮次、换后端也能用、离线可跑。

### 位置永远不会丢

桌宠最容易出的问题是「被拖飞就再也找不着」。这里的做法：

1. **尺寸用 `offsetWidth/offsetHeight` 量** —— 不用 `getBoundingClientRect()`，
   因为祖先元素带 `transform/perspective` 时它给出的坐标会被整体平移
2. **边界用视口尺寸算**，保证**整只**留在可见区内
3. **装不下就等比 `scale()` 缩小**，而不是把它推出屏幕
4. 窗口 resize / 转屏 / 软键盘弹出都会重新夹一次
5. **放宽了"放不下就回退"的判断**：桌宠比屏幕宽时，贴边反而是唯一能看见它的放法

### 顺手修掉了一个酒馆自身的坑

酒馆的 `public/style.css` 里有：

```css
html { -webkit-perspective: 1000; }   /* 为修 Chrome 模糊闪烁加的 */
```

`perspective` 会让 `<html>` 成为**所有 `position:fixed` 后代的包含块**，
导致 fixed 元素被整体平移出屏幕。引擎会在运行时把根元素的
`transform/perspective`（含 `-webkit-` 前缀）摁成 `none`，**不修改酒馆的任何文件**。

### 契约校验

模型输出不受控，所以每个字段都按 `contract` 校验：
取值不在 `values` 里的直接丢弃并补默认值，并在控制台给警告。
作者在导入包时也会做静态校验（比如 `enum` 的 `map` 有契约外的键、`skipWhen` 引用了不存在的字段，都会直接报错）。

### 图层条件显示

任何图层都能加 `skipWhen`，用来做"某个字段有值时这一层不出现"：

```json
{ "type": "enum", "field": "brow", "skipWhen": "blackface", "map": { ... } }
```

典型用途：整脸替换图（黑脸）一出，就不再叠眉/眼/嘴，避免两张脸叠在一起。

### 图层微调

每个图层、以及 `list` 的**每个取值**都能单独调位置/缩放/旋转/透明度：

```json
{
  "type": "list", "field": "items",
  "map": { "hat": "hat.png", "scarf": "scarf.png" },
  "transforms": { "hat": { "y": -30, "scale": 1.2 } }
}
```

## 兼容性

- SillyTavern 1.18.0 实测可用
- 不依赖酒馆助手（Tavern Helper）。有它时优先用它的 API 读消息/订阅事件，
  没有就回退到酒馆原生 `context.chat` + 轮询
- 导出的独立脚本同样两者都能跑

## 开发说明

各核心模块都是独立的 IIFE，挂在 `window.Pet*` 命名空间下，没有构建步骤。
改完直接刷新酒馆页面即生效。

调试接口（控制台可用）：

```js
window.__SHUSHU_PET__          // 扩展状态：name / version / base / ready / error
window.PetEngine.getState()    // 运行状态：running / packageId / mounted / avatar
window.PetRegistry.listPackages()
```

导出的独立脚本会挂 `window.__SHUSHU_PET_STANDALONE__`，
提供 `refresh()` / `mount()` / `hide()` / `resolveLayers()`，方便排查。
