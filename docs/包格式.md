# 鼠鼠桌宠 · 包格式说明（作者只需要看这一份）

> 你**不用写任何 JavaScript 或 CSS**。
> 你只需要准备三样东西：**标签名**、**字段契约**、**立绘素材**。
> 剩下的解析、渲染、动作、拖拽、存档、定位、保活全部由扩展负责。

---

## 一、你要做的三件事

### 1. 决定一个标签名

模型每次回复时，会把桌宠状态包在一个标签里，例如：

```
鼠鼠从屏幕角落探出头来。
<PetState>{"eyes":"smile","mouth":"cat","speech":"在的。"}</PetState>
```

这里的 `PetState` 就是**标签名**。换成什么都行（`鼠鼠状态`、`Pet`、`ShuState`……），
只要你的提示词和包里的 `contract.tag` 一致。

> **必须成对闭合**：`<PetState>...</PetState>`。

### 2. 写字段契约（`contract`）

告诉引擎"这个标签里可能出现哪些字段、每个字段能取什么值"。
引擎会据此**校验模型的输出**：写了没声明的取值会被丢弃并补默认值，防止模型乱写把桌宠弄花。

```json
"contract": {
  "tag": "PetState",
  "lookback": 10,
  "defaults": { "eyes": "normal", "motion": "still", "speech": "在的。" },
  "fields": [
    { "name": "eyes",   "type": "enum", "values": ["normal","smile","cry"], "default": "normal" },
    { "name": "mouth",  "type": "enum", "values": ["cat","open","flat"],    "default": "cat" },
    { "name": "blush",  "type": "bool", "default": false },
    { "name": "items",  "type": "list", "values": ["hat","scarf"], "maxItems": 2, "default": [] },
    { "name": "speech", "type": "text", "default": "在的。" }
  ]
}
```

**字段类型**：

| type | 含义 | 额外要求 |
|---|---|---|
| `enum` | 单选，值必须在你列的 `values` 里 | 必填 `values` |
| `bool` | 真/假 | — |
| `number` | 数字，可加 `min`/`max` | — |
| `list` | 多选，会做去重外的清洗 | 可选 `values`、`maxItems` |
| `text` | 任意文字（台词走这个） | — |

**`prompt` 字段（可选但强烈建议）**：把上面这套写成给模型看的说明，方便你复制进角色卡。
引擎不会自动把它塞进提示词，它只作为"随手可取"的文案存在包里。

### 3. 准备立绘素材

两种放法：

- **外链**：直接写完整 URL（`https://.../eyes_smile.png`）
- **包内相对路径**：跟 JSON 放一起，写 `"eyes_smile.png"`，引擎会相对包所在目录解析

> 立绘建议：**透明背景 PNG，所有图层尺寸一致**，这样叠起来不会错位。

## 二、把素材挂到字段上（`layers`）

`layers` 是一张列表，**顺序 = 叠放顺序，后面的盖在前面上**。

```json
"layers": [
  { "type": "base", "z": 10, "asset": "base.png" },
  { "type": "enum", "z": 21, "field": "eyes",  "map": { "smile": "eyes_smile.png", "cry": "eyes_cry.png" } },
  { "type": "enum", "z": 22, "field": "mouth", "map": { "cat": "mouth_cat.png", "open": "mouth_open.png" } },
  { "type": "list", "z": 30, "field": "items", "map": { "hat": "hat.png", "scarf": "scarf.png" } }
]
```

| type | 什么时候显示 | 需要 |
|---|---|---|
| `base` | 永远显示（最底层） | `asset` |
| `enum` | 当 `data[field]` 等于 `map` 里的某个键 | `field` + `map` |
| `bool` | 当字段为真/假（`map` 用 `"true"`/`"false"` 当键） | `field` + `map` |
| `list` | 字段是数组时，**每个元素各叠一层**（多配饰就靠它） | `field` + `map` |
| `exists` | 字段有值就显示固定图 | `field` + `asset` |

**`z`** 是叠放层级，不写就按列表顺序自动分配（第 n 个 = n×10）。

**条件显示 `skipWhen`**：任何图层都能加，用来做"某个字段有值时这一层不出现"。
比如原版桌宠的**黑脸覆盖**——一旦是黑脸，就不该再叠眉毛/眼睛/嘴：

```json
{ "type": "enum", "field": "brow", "skipWhen": "blackface", "map": { ... } }
```

三种写法：

| 写法 | 含义 |
|---|---|
| `"skipWhen": "blackface"` | 该字段**有值**（非空串/非空数组/非 false）→ 跳过本层 |
| `"skipWhen": { "field": "mood", "equals": ["angry"] }` | 取值命中 → 跳过 |
| `"skipWhen": { "field": "mood", "notEquals": ["calm"] }` | 取值不含 → 跳过 |

还有 `{"field":"x","empty":true}`（为空时跳过）和 `{"field":"x","notEmpty":true}`。

> `skipWhen` 和图层 `field` 引用的字段**必须在契约里存在**，否则会被校验拦下。

> **常见错法**：`enum` 的 `map` 里写了契约 `values` 之外的键 —— 那些图**永远显示不出来**。
> 扩展在导入时会直接报错提醒你。

## 三、动作（`motions`）

只写**声明**，不用写 CSS。引擎会自己生成 `@keyframes`。

```json
"motions": {
  "still":   {},
  "bounce":  { "keyframes": { "0%,100%": "transform:translateY(0)", "50%": "transform:translateY(-15px)" },
               "duration": ".5s", "iteration": "2" },
  "spin":    { "keyframes": { "0%": "transform:rotate(0)", "100%": "transform:rotate(360deg)" },
               "duration": ".85s", "iteration": "1" }
}
```

| 键 | 说明 | 默认 |
|---|---|---|
| `keyframes` | `{ "0%": "css声明", "50%": "..." }` | 必填（`still` 可为空） |
| `duration` | 如 `".5s"` | `1s` |
| `timing` | `ease-in-out` / `linear` … | `ease-in-out` |
| `iteration` | `"2"` / `"infinite"` | `1` |
| `direction` / `fill` | 标准 CSS 值 | `normal` / `both` |
| `animation` | 想完全自己控制时，直接写完整 `animation` 值，会覆盖上面 | — |

**动作名要出现在字段契约里**（通常是 `motion` 字段的 `values`），否则模型写出来会被过滤掉。

**缩放注意**：窗口太窄时引擎会给整个桌宠加 `transform: scale()`。
所以动作里**别用 `translate(-50%,-50%)` 这类依赖自身尺寸的居中写法**，会跟缩放打架。用 `translateY` / `rotate` / `scale` 这类相对变换最安全。

## 四、渲染参数（`render`，都可选）

```json
"render": {
  "size": "25.5vh",          // 桌宠尺寸，建议按屏高算
  "zIndex": 3500,            // 高于酒馆抽屉(3000)，低于弹窗(9999)
  "startRight": "1vh",       // 初次出现的距右
  "startBottom": "6vh",      // 初次出现的距底
  "bubbleBg": "#1c1c1c",     // 气泡底色
  "bubbleColor": "#e0e0e0"   // 气泡字色
}
```

> 位置不用你操心：引擎保证**整只桌宠始终留在可见区内**，
> 窗口缩小会自动夹回，装不下会自动等比缩放。拖飞了也会被拉回来。

## 五、完整最小示例

```json
{
  "id": "my-pet",
  "name": "我的桌宠",
  "contract": {
    "tag": "MyPet",
    "lookback": 10,
    "defaults": { "eyes": "normal", "motion": "still", "speech": "在的。" },
    "fields": [
      { "name": "eyes",   "type": "enum", "values": ["normal", "happy"], "default": "normal" },
      { "name": "motion", "type": "enum", "values": ["still", "bounce"], "default": "still" },
      { "name": "speech", "type": "text", "default": "在的。" }
    ]
  },
  "layers": [
    { "type": "base", "asset": "base.png" },
    { "type": "enum", "field": "eyes", "map": { "happy": "eyes_happy.png" } }
  ],
  "motions": {
    "still": {},
    "bounce": { "keyframes": { "0%,100%": "transform:translateY(0)", "50%": "transform:translateY(-12px)" }, "duration": ".5s", "iteration": "2" }
  }
}
```

配套的提示词（贴进角色卡）：

```
每次回复结束后，另起一行输出桌宠状态，标签名必须是 MyPet：
<MyPet>{"eyes":"normal|happy","motion":"still|bounce","speech":"不超过30字的短台词"}</MyPet>
eyes 默认 normal，motion 默认 still。不要在标签外解释这个标签。
```

## 六、装到酒馆里

1. **导入包**：酒馆里点左侧的「鼠鼠桌宠」按钮 → **导入 JSON** → 选你的包文件
   （导入后会自动绑定到当前角色）
2. **给别的角色用**：在面板里对着目标包点「绑定当前角色」
3. **全局默认**：想让所有角色都用某个包，点「设为默认」

**自测清单**：

- [ ] 标签名和提示词一致，且成对闭合
- [ ] 所有 `enum` 的 `map` 键都在契约 `values` 里
- [ ] 立绘都是透明 PNG 且尺寸一致
- [ ] 动作名在 `motion` 字段的 `values` 里
- [ ] 模型输出后，桌宠立刻跟着变

## 七、常见问题

**桌宠不出现**
1. 当前聊天最近 10 条 AI 消息里有没有你的标签？没有就按设计隐藏
2. 标签名大小写对不上？`<PetState>` 和 `<petstate>` 是两回事
3. 面板里确认包已绑定到当前角色
4. JSON 里有没有尾逗号、中文引号 —— 引擎会尝试容错，但严重错误救不回来

**脸对不上 / 少了配件**
- 模型的取值没在契约 `values` 里 → 被过滤了。看浏览器控制台，会有 `收到未定义取值` 警告

**图片加载不出来**
- 外链被墙就换本地文件；本地文件确认路径和 JSON 的相对关系

**桌宠跑到屏幕外**
- 不该发生。真遇到就点面板里的「重置位置」，并把情况反馈一下
